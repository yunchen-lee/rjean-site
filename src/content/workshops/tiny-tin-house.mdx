# Tiny Tin House

Tiny Tin House is a creative coding workshop that connects digital pattern-making with physical craft. Participants learn how code can generate visual textures and how those textures can become materials for hands-on making.

## From Code to Texture

The workshop begins in p5.js. Participants build layered patterns with colors, repeated shapes, lines, arcs, and controlled randomness. Step by step, these simple coding tools create surfaces inspired by worn, painted, and rusted metal sheets.

## From Texture to House

The generated textures are printed, cut, folded, and attached to cardboard structures. By combining digital images with physical materials, each participant turns the same basic house form into a different small building.

## Workshop Outcome

The final models show how creative coding can move beyond the screen. Code becomes a way to design material qualities, while cutting, folding, and assembling reveal new possibilities through making.
